Pertanyaan yang Sering Diajukan (FAQ)

Apa bedanya JPG dan JPEG? ▼

Tidak ada perbedaan teknis! Keduanya mengacu pada format kompresi gambar yang sama dari Joint Photographic Experts Group. Nama ekstensi tiga huruf ".jpg" dulu populer di sistem Windows lawas (MS-DOS yang hanya mendukung ekstensi 3 karakter), sementara ".jpeg" adalah nama resminya.

Bagaimana cara mengecilkan foto agar di bawah 200 KB untuk CPNS? ▼

Cukup klik tab "Target Ukuran (KB/MB)" di kotak pengaturan, pilih preset "★ 200 KB (CPNS / BKN)", lalu unggah foto Anda. Sistem kami secara otomatis mengalkulasi kualitas optimal agar ukuran file tepat berada di bawah 200 KB tanpa mengurangi ketajaman wajah secara berlebihan!

Apakah foto saya aman dan tidak bocor? ▼

Sangat aman 100%! Aplikasi ini dirancang sepenuhnya bekerja secara lokal di dalam browser web perangkat Anda menggunakan teknologi HTML5 Canvas dan Web Workers. Tidak ada satu pun gambar atau data Anda yang dikirim ke server internet.
